# 🚚 MRW Cashea Logistics

Módulo de trazabilidad y conciliación logística de despachos de encomiendas enviadas a través de **MRW** para compras financiadas con Cashea.

## 🎯 Funcionalidades
* Seguimiento de paquetes y guías de envío (`mrw.py`, `mrw_cashea.py`).
* Conciliación entre órdenes facturadas y números de guía generados.
* Genera bitácoras de envíos `reports/mrw.xlsx` y `reports/packages_recorded.csv`.

## 🚀 Ejecución
```bash
uv run python mrw_cashea.py
```
