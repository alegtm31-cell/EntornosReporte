# 👥 Clientes Al Mayor

Módulo de segmentación y distribución de cartera de clientes mayoristas a la fuerza de ventas activa.

## 🎯 Funcionalidades
* Realiza el cruce entre ventas históricas, maestros de clientes, vendedores y estados territoriales.
* Identifica la última compra y clasifica a los clientes en Activos o Inactivos.
* Distribuye automáticamente las carteras a cada vendedor activo (Abraham Muñoz, Alexander Mujica, Andreina Perdomo, Anthony Lara, Desiree Rangel, Kirvin Ramirez, Scarlet Gonzalez).

## 🚀 Ejecución
```bash
uv run python clientes_almayor.py
```
