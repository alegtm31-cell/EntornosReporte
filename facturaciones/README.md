# 🧾 Facturaciones & Conciliación Fiscal

Módulo de extracción, limpieza y auditoría de documentos de facturación y archivos PDF de ventas.

## 🎯 Funcionalidades
* Limpieza y parseo de datos de facturas en PDF (`limpieza_pdf/`).
* Cruce y validación de numeración correlativa y montos reportados en el libro de ventas.
* Exportación de reportes de auditoría en Excel (`reportes/facturacion_*.xlsx`).

## 🚀 Ejecución
```bash
uv run python facturaciones.py
```
