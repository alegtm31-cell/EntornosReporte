# 🎯 Metas RRHH & Ventas

Módulo para el seguimiento y evaluación del cumplimiento de cuotas de ventas por asesor comercial y cálculo de incentivos/comisiones.

## 🎯 Funcionalidades
* Ejecuta consultas analíticas (`resultados.sql`) sobre la base de datos empresarial.
* Compara el volumen facturado individual frente a las metas asignadas por la gerencia para cada periodo comercial.
