# 📊 Cashea Stats

Módulo de análisis transaccional y estadístico de las compras procesadas con financiamiento **Cashea**.

## 🎯 Funcionalidades
* Procesa los datos de compras y financiamientos obtenidos desde la base de datos empresarial.
* Analiza frecuencia de compra, ticket promedio y comportamiento de los clientes usuarios de Cashea.
* Genera el informe periódico `reports/cashea.xlsx`.

## 🚀 Ejecución
```bash
uv run python cashea_stats.py
```
