# 📦 Sending Zoom Logistics

Módulo de seguimiento y auditoría logística de paquetes y encomiendas despachadas mediante **ZOOM**.

## 🎯 Funcionalidades
* Procesa el estado de las guías de transporte emitidas para clientes mayoristas y detal.
* Consolida métricas de tiempos de entrega y novedades en ruta en `reports/kpi_zoom.xlsx`.

## 🚀 Ejecución
```bash
uv run python sending_zoom.py
```
