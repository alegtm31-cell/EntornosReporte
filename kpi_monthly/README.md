# 📅 KPI Monthly

Módulo de consolidación mensual de indicadores clave de rendimiento (KPIs) comerciales para la dirección de la empresa.

## 🎯 Funcionalidades
* Compara el desempeño y volumen de ventas entre el canal al detal y el canal al mayor.
* Genera métricas de facturación acumulada, cumplimiento mensual y proyecciones.
* Exporta el informe gerencial `kpi_reports/kpi_monthly.xlsx`.

## 🚀 Ejecución
```bash
uv run python kpi_monthly.py
```
